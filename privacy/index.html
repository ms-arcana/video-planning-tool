About this tool

The Video Planning Research Tool is a personal, command-line research tool operated by ms-arcana, an individual YouTube creator, to plan original videos for my own YouTube channel. It runs locally on my own computer. It is not offered to anyone else, has no user accounts, and generates no revenue. (The videos I produce may earn ad revenue through the YouTube Partner Program; this tool and the API data it uses are not monetized.)

Use of YouTube API Services

This tool uses YouTube API Services. By using this tool, users are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the tool accesses

The tool accesses only publicly available data returned by the YouTube Data API:

  • Videos: video IDs, titles, publish dates, durations, and view, like and comment counts.
  • Channels: channel IDs, creation dates, and public subscriber and video counts.
  • For an optional aggregate analysis: the channel IDs of people who posted public comments. Comment text is not stored.

The tool does not ask anyone to sign in and does not access any Google account or any private data.

How the information is used, processed and shared

  • The data are used only to compute aggregate statistics for planning my own videos (for example, percentile ranges of view counts).
  • Commenter channel IDs are converted immediately into keyed (HMAC) hashes. The key is stored separately, and only aggregate counts are kept.
  • I do not sell, publish or share the data or the statistics derived from them with anyone, inside or outside this project.

Advertising and third-party content

Neither this tool nor these web pages show advertising, and no third party serves content through them.

Cookies and similar technologies

These pages do not set cookies and do not use analytics or tracking. They load no external scripts, fonts or images. The pages are hosted on GitHub Pages, and GitHub may collect technical information such as IP addresses, as described in the GitHub General Privacy Statement.

Retention and deletion

API data are kept for at most 30 days and are then refreshed or deleted, unless a longer period is expressly permitted to me under YouTube's Additional Policies for Derived Metrics and Data Storage. If you want data related to your channel deleted, contact me at the address below and I will delete it within 7 days.

Revoking access

This tool does not ask anyone to grant access to a Google account. If that ever changes, users will be able to revoke the tool's access at any time through the Google security settings page.

Changes to this policy

If this policy changes, I will update this page and the "Last updated" date above.

Contact

このツールについて

Video Planning Research Tool は、個人の YouTube クリエイターである ms-arcana が、自分の YouTube チャンネルのオリジナル動画を企画するために使う、個人用のコマンドラインの調査ツールです。自分のコンピューターで動かします。誰にも提供せず、ユーザーアカウントもなく、このツールで収益は得ません（制作した動画は YouTube パートナープログラムで広告収益を得ることがありますが、このツールと、ツールが使う API のデータは収益化しません）。

YouTube API サービスの利用

このツールは YouTube API サービスを使います。このツールを使うことで、利用者は YouTube 利用規約に拘束されることに同意したことになります。Google によるデータの扱いは、Google プライバシーポリシーに記載されています。

取得する情報

YouTube Data API が返す、公開の情報だけを取得します。

  • 動画: 動画 ID、題名、公開日、長さ、再生・高評価・コメントの数
  • チャンネル: チャンネル ID、開設日、公開の登録者数と動画数
  • 任意の集計分析のため: 公開コメントを投稿した人のチャンネル ID（コメント本文は保存しません）

このツールはログインを求めず、Google アカウントや非公開の情報には一切アクセスしません。

利用・処理・共有

  • データは、自分の動画の企画のための集計統計（再生数の分位点など）の作成にだけ使います。
  • 投稿者のチャンネル ID は、すぐに鍵付きハッシュ（HMAC）に変換します。鍵は別に保管し、集計だけを残します。
  • データや、データから作った統計を、販売・公開・共有することはありません。

広告と第三者のコンテンツ

このツールとこれらのページには広告を表示せず、第三者がコンテンツを配信することもありません。

Cookie などの技術

これらのページは Cookie を使わず、アクセス解析や追跡もしません。外部のスクリプト・フォント・画像も読み込みません。ページは GitHub Pages で公開しており、GitHub が IP アドレスなどの技術的な情報を収集することがあります（GitHub のプライバシーに関する声明）。

保存期間と削除

API のデータは最長30日保存し、その後は取り直すか削除します（YouTube の「派生指標とデータ保存に関する追加ポリシー」で長い期間を明示的に許可された場合を除く）。ご自身のチャンネルに関するデータの削除を希望する場合は、下の連絡先までご連絡ください。7日以内に削除します。
