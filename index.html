Video Planning Research Tool

A personal, command-line research tool that I (ms-arcana, an individual YouTube creator) use to plan original videos for my own YouTube channel.

What it is

  • It runs locally on my own computer. There is no hosted interface, no sign-in, and no user accounts.
  • It is not offered to anyone else and generates no revenue. The videos I produce may earn ad revenue through the YouTube Partner Program; this tool and the data it uses are not monetized.

What it does

The tool uses YouTube API Services (YouTube Data API v3: search.list, videos.list, channels.list, playlistItems.list, commentThreads.list) to read publicly available video and channel metadata and statistics. From these, it computes aggregate benchmarks, such as percentile ranges of view counts by video format, that help me decide which video ideas to try. The results are used only for my own planning and are never published or shared.

How data is handled

  • Only public data is accessed. The tool does not access anyone's Google account.
  • Comment text is never stored. Commenter channel IDs are converted immediately into keyed hashes, and only aggregate counts are kept.
  • API data is kept for at most 30 days and is then refreshed or deleted.
